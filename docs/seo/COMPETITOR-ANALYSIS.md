## Lecture stratégique

1. **Le marché est dominé par le contenu « cours » et les abonnements.** Le créneau « aventure narrative sans violence » avec gestes réels est peu visible dans ces résultats ; c'est une hypothèse à confirmer avec une vraie étude de mots-clés.
2. **Les fiches stores concurrentes parlent surtout aux 4–9 ans.** NOUR peut viser les 8–12 ans et les familles.
3. **Les faiblesses repérées par les utilisateurs** (avis cités dans les résultats) : abonnements qui bloquent la suite du contenu, bugs. Argument possible : « chapitre 1 complet gratuit, sans compte ».
4. **Signaux de confiance à égaler** : classification d'âge claire, politique de confidentialité, sources des hadiths et mention de relecture.
